# Phase 4 — Daily Academic Operations

## الهدف
بناء العمليات اليومية للمدرسة والمعهد.

## Attendance
- Present
- Absent
- Late
- Excused

## Homework
الأستاذ يمكن أن يضيف واجباً مع:
- Title.
- Description.
- Subject.
- Due Date.
- Attachments.
- Target.

Target:
- Grade.
- Section.
- Subject.
- Group.
- Specific Students.

## Schedule
### School
`Grade / Section -> Weekly Schedule`

### Institute
`Subject / Group -> Sessions Schedule`

## Academic Exams
الامتحان الرسمي منفصل عن الاختبار المؤتمت.

يحتوي:
- Subject.
- Grade.
- Section? إذا الامتحان لشعبة.
- Title.
- Exam Type.
- Exam Date.
- Max Score.
- Status.

## Grades via Excel
Flow:
`Create Exam -> Download Template -> Fill -> Upload -> Validate -> Preview -> Draft -> Publish`

Validation:
- الطالب موجود.
- تابع للTarget.
- لا Duplicate.
- Score valid.
- Score <= Max Score.

## Notifications
عند Publish:
- Student notification.
- خيار Notify Parents Yes/No.

يفضل فصل:
- Visible To Parent.
- Notify Parent.

## Deliverables
- Attendance.
- Homework.
- Schedule.
- Academic Exams.
- Excel Grade Import.
- Draft/Publish.
- Gradebook.
- Student Timeline.
