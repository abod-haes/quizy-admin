# Phase 3 — School & Institute Academic Structure

## الهدف
بناء الفرق الفعلي بين المدرسة والمعهد.

## School
- Academic Years.
- Grades.
- Sections.
- Subjects.
- School Enrollment:
  `Student -> Academic Year -> Grade -> Section`

## Institute
- Subjects.
- Groups.
- Institute Enrollment:
  `Student -> Subject -> Group`
- الطالب يمكن أن يملك عدة Enrollments.

## Assignments
### School Teacher
`Teacher -> Subject -> Grade / Section`

### Institute Teacher
`Teacher -> Subject -> Group`

### Supervisor
`Supervisor -> Assigned Grades / Sections`

## Student Management
- Add/Edit/Archive/Search.
- Parent links.
- Phone.
- Academic assignment.
- Institute enrollments.

## Imports
Excel import للطلاب مع:
- Validate.
- Preview.
- Confirm.
- Error report.

## Bulk Actions
- Move section.
- Assign group.
- Archive.
- Parent linking.

## Deliverables
- School academic structure.
- Institute academic structure.
- Enrollments.
- Teacher/Supervisor assignment.
- Student import.
- Bulk actions.
